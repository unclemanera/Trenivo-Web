# Web for cats
Tento web je věnován kočkám. Dozvíte se zde základní informace o kočkách, jejich životě, potravě a různých plemenech. Představíme si například britskou, siamskou a mainskou mývalí kočku.
Najdete zde také zajímavosti ze světa koček, fotografie a další informace, které vám pomohou kočky lépe poznat.
Web bude laděný do žluté, béžové a šedé barvy a nahoře bude jednoduchá navigace, pomocí které se můžete rychle přesunout na jednotlivé části stránky.
